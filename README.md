# 丰嘉盈 · 原生微信小程序

原生 WXML / WXSS / JavaScript，无 uni-app，无前端框架，无后端依赖。依据 `docs/丰嘉盈_技术设计_v1.0` 实现，角色色为顾客红、商户蓝、代理紫。

## 运行

1. 使用微信开发者工具导入整个 `E:\FJY_program\wx_app` 文件夹。
2. `project.config.json` 已配置 AppID `wx08a936770c8125e8`；预览/真机调试时，请使用具有该小程序开发权限的微信账号登录开发者工具。
3. 编译 `pages/home/index`。无需 npm 安装或构建。

底部包含自定义固定导航：首页、发现、权益、我的。三种角色入口固定可见，进入经营台时检查演示身份。二级页保留微信原生返回导航。

## 体验流程

- 短信登录：任意11位手机号，验证码 `123456`。模拟微信手机号快捷登录使用 `13800138000`。
- 短信登录后，在“我的”点击模拟微信绑定，再参与活动。模拟快捷登录已标记绑定。
- 首页“新朋友的第一份见面礼”为100%中奖演示；其他活动按概率抽样，中奖人数为上限。
- 自动配号：中奖后每2秒查询 mock 状态，两次查询后模拟出票完成。
- 手动选号：进入原生模拟选号页选择6个号码，提交后回到结果页继续查单。手选15分钟超时释放权益，不返还参与次数。
- 商户：入驻免审核；邀请码留空为平台直客，`JHY2026` 绑定演示代理。进入经营台体验创建活动、草稿发布、暂停/恢复/结束、采购、原批次退款、券模板、一次核销与定向礼包。
- 代理：申请后点击明确标识的“开发演示：模拟审核通过”。体验采购库存、转售价目表、邀请、名下商户、接管申请和转售货款。
- 核销：顾客在权益→卡券生成60秒动态口令，商户在核销页粘贴；扫描入口供后续真实码接入。当前展示文字口令，不生成虚假二维码。
- 礼包：商户创建时预占，复制一次性口令；对应手机号顾客在权益→领礼包输入后领取。未领取礼包可撤销，24小时过期释放。

## 页面

25个页面：公共首页、发现、权益、我的、登录、店铺、活动、确认参与、领取结果、模拟选号、商户入驻、代理申请、经营台、创建活动、记录、钱包、采购、退款、核销/券模板、礼包、价目表、名下商户、货款、邀请、资料。

四种活动玩法提供独立展示组件：幸运转盘、刮刮乐、九宫格、直接领取。点击进入统一确认流程；抽奖结果只在 mock 服务层产生。

## Mock 与接入

`services/mock.js` 集中处理模拟登录、授权、状态机、幂等、批次可用量、权益冻结、模拟支付/出票与一次核销；`utils/page.js` 提供页面生命周期和交互逻辑；`custom-tab-bar` 是原生自定义底部栏。

数据保存在本机 `fjy-native-v1`，支持按手机号切换隔离和恢复。演示手机号不是实际认证；用户输入仅存本地。“我的→重置本地演示数据”可恢复初始状态。购买、短信、微信、出票全部模拟，不产生真实资金/彩票。退款仅冻结和提交，真实双人审核/支付回调由未来后端实现。两端当前不共享数据。

真实接入时，应替换 mock request 为统一 HTTPS 请求封装，增加 JWT/串行刷新/设备会话/Membership/稳定幂等键和真实错误码。当前选号是原生 mock，未配置不可信上游 H5；未来 web-view 必须限制 HTTPS 白名单，返回只触发查单。生产禁用所有模拟入口。
